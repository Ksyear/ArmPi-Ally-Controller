# 보안

## 위협 모델

이 앱은 같은 와이파이에 있는 로봇과 통신한다. 같은 망에 있는 다른 장치는 다음을 할 수 있다고 본다.

- 로봇을 사칭한다: 가짜 검색 응답, 가짜 rosbridge, 가짜 카메라.
- 로봇과 앱 사이의 트래픽을 위조하거나 바꾼다.
- 거대하거나 망가진 입력을 보낸다.

이 밖에 로컬 파일(설정·기록), DLL 검색 경로, 외부 코드와 CI도 함께 점검했다.

## 받아들이는 위험(설계)

- **인증·암호화가 없다.** 앱과 로봇 사이 통신(UDP 5001 조종, WebSocket 9090 상태, HTTP 8080 영상)이 그렇다. 로봇 쪽 규격이라 앱만 고쳐서는 바꿀 수 없다.
  - 같은 와이파이에 있는 누구나 로봇에 명령을 보내고, 로봇이 보내는 상태·영상을 위조할 수 있다.
  - **신뢰할 수 있는 사설 망(개인 핫스팟·전용 AP)에서만 쓰고, 공용 와이파이에서는 쓰지 않는다.**
- **'로봇 찾기'는 응답한 기기를 그대로 보여 준다.** 목록에 기기 ID 앞 8자리를 함께 보이니, 처음 연결할 때 로봇의 주소·ID와 맞는지 확인한다.
- **연결형 UDP는 송신지를 걸러 낼 뿐 인증이 아니다.** 위조된 응답은 조종을 방해하거나(고장·다른 조종자로 보이게) 표시를 속일 수 있다. 다만 로봇을 움직이게 만들 수는 없다(로봇은 이 앱이 보낸 명령만 따른다). 최종 정지 수단은 로봇의 전원 스위치다.

## 점검과 수정(v0.1.0)

| 항목 | 위험 | 조치 |
|---|---|---|
| 카메라 이미지 크기 | 작은 PNG가 거대한 이미지를 선언해 메모리를 고갈시킴 | 해독 전에 헤더로 치수를 확인한다(최대 3840×2160, 한 변 4096). 프레임은 8 MB 이하. 프레임은 복사 없이 공유 |
| MJPEG 파서 | 끝 표시 없이 계속 보내 버퍼가 무한히 커짐 | 파트 헤더 64 KB, 파트 16 MB 상한. 경계 문자열 형식 검사. 5초 동안 데이터가 없으면 다시 연결 |
| 원격 상태로 팔 목표 이동 | 위조된 "현재 자세"로 팔 목표를 엉뚱한 곳으로 옮김 | 작업 공간 밖 값 무시. 0.5초 안의 새 상태만 쓴다. 로봇 보정 따라가기는 내 목표에서 5 cm 안일 때만. 큰 이동은 경고. 원격 값은 '로봇이 수락한 값'으로 기록하지 않음 |
| WebSocket·JSON 크기 | 거대 메시지로 메모리 증폭 | 메시지 8 MB, JSON 1 MB 상한. 진단 기록은 메시지마다 4 KB만 보관. 다시 연결 간격을 2초에서 10초까지 늘림 |
| 기록·알림 문자열 | 로봇이 보낸 긴 문자열·제어 문자 | 512바이트로 자르고(UTF-8 경계) 제어 문자를 지움. 기록 파일은 최근 20개만 보관 |
| 검색 응답의 이름 | 화면 깨짐·ID 충돌 | 48자, 출력 가능한 문자만. 기기 ID 표시 |
| 고장 위조 | 세션이 막혔는데 이유가 안 보임 | 상단에 "고장 보고됨 — 새 세션" 표시 |
| DLL 검색 경로 | exe 옆에 같은 이름의 DLL을 두면 실행 시 로드됨 | XInput 등 실행 중에 읽는 DLL은 System32에서만 읽음(`LoadLibraryExW`, `SetDefaultDllDirectories`) |
| 설정 파일 | 주소·URL에 줄바꿈 등이 들어감 | 주소는 숫자·영문·점·하이픈만, URL의 공백·줄바꿈 거부 |
| 빌드 | 메모리 손상 완화 | ASLR(고엔트로피)·DEP를 명시하고 CI에서 PE 헤더를 검사. 스택 보호·`_FORTIFY_SOURCE` |
| CI | 공급망 | 액션을 커밋 SHA로 고정, 토큰 읽기 전용, 시험용 가짜 로봇 소스를 커밋으로 고정 |

각 항목에는 단위 시험(`security_limits`)과 가짜 로봇 종단 시험이 있다.

## 알려진 남은 위험

- **실행 파일이 함께 불러오는 DLL**(예: `d3dcompiler_47.dll`)은 Windows 규칙상 exe 폴더를 먼저 찾는다. 배포할 때는 관리자만 쓸 수 있는 폴더(예: `Program Files`)에 설치하기를 권한다.
- 검색한 기기의 ID를 기억해 두었다가 바뀌면 경고하는 기능은 아직 없다.
- 연결을 끊을 때 응답이 없는 카메라·rosbridge 연결을 정리하느라 화면이 몇 초 멈출 수 있다. 조종 스레드는 먼저 멈추고 중립·disconnect를 보내므로 로봇 안전에는 영향이 없다.
- 코드 서명이 없다. 스마트 앱 컨트롤이 켜진 Windows에서는 실행이 막힌다.
