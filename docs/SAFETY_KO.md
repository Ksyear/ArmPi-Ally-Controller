# 안전 설계

로봇은 바퀴로 움직이고 팔에는 끼일 곳이 있다. 이 앱은 "놓으면 멈춘다, 저절로 다시 움직이지 않는다"를 기본으로 한다. 로봇 쪽 규칙(Protocol v3: 채널별 중립 확인, watchdog 0.4초, lease 1초, 비상정지 latch)은 그대로 따르고, 앱이 그 위에 제한을 더한다.

## 규칙

1. **비상정지는 한 번에.** B, Space, 화면의 빨간 버튼(손가락이 닿는 순간 발동). 창 포커스가 없어도 B는 듣는다. 로봇이 ACK를 줄 때까지 50 ms마다 다시 보낸다(조종 스레드가 혼자 처리하므로 화면이 멈춰도 계속된다).
2. **해제는 길게.** View 또는 화면 버튼을 0.8초. 해제한 뒤에도 차체는 스틱을 놓았다가 다시 밀어야, 팔은 LB를 다시 눌러야 움직인다.
3. **팔은 데드맨.** LB(또는 Shift)를 누르는 동안만 팔 채널이 활성이다. 터치로 켜 둔 팔은 60초 무입력이면 꺼진다.
4. **팔 목표는 점프하지 않는다.** 스틱·터치 그림·숫자 어느 입력이든 손끝 0.15 m/s, pitch 0.6 rad/s, 그리퍼 0.8/s 상한으로 목표에 다가간다.
5. **닿지 않는 곳으로 앞서 나가지 않는다.** 로봇과 같은 목표 보정 규칙(`TargetProjector`)으로 앱에서 먼저 보정하고, 로봇이 보정했다고 알리면 앱 목표를 로봇이 실제로 쓰는 목표로 되돌린다. 이때 짧게 진동한다.
6. **포커스를 잃으면 중립.** 다른 창으로 가거나 최소화하면 입력을 모두 내리고 팔을 끈다. 돌아와도 저절로 다시 움직이지 않는다.
7. **입력이 끊기면 중립.** 화면 스레드가 0.3초 넘게 입력을 넘기지 않으면 조종 스레드가 중립을 보낸다. 앱이 통째로 죽으면 로봇 watchdog(0.4초)이 차체를 세우고 팔을 그 자리에 둔다.
8. **패드가 빠지면 중립.** 다시 꽂히면 스틱이 가운데로 돌아온 뒤에만 입력을 받는다.
9. **조종 중 화면이 꺼지지 않게** 연결된 동안 `SetThreadExecutionState`로 잠자기를 막는다.
10. **한 기기에 한 조종기.** 같은 Ally에서 두 번 실행하면 두 번째는 뜨지 않는다.
11. **로봇 전체 해제**(`/armpi/reset_estop`)는 길게 누름 + 확인 두 단계. 게임패드로는 할 수 없다.

## 자동 집기(집기 탭)

자동 동작도 위 규칙 1–11을 모두 그대로 따른다. 그 위에 다음을 더한다.

12. **자동 동작도 데드맨.** 팔은 A(또는 화면의 '누르고 있는 동안 진행')를 **누르고 있는 동안만** 움직인다. 놓으면 팔 목표를 그 자리에서 멈추고 '일시정지'가 된다. 다시 눌러도 다음 단계로 건너뛰지 않고 **지금 단계의 목표를 다시** 보낸다. 시작과 재개는 **새로 누를 때만** 된다(누른 채로 있던 A로는 시작되지 않는다).
13. **사람이 끼어들면 선다.** 자동 집기 중에 스틱·LB·팔 버튼으로 팔을 움직이거나, 다른 팔 명령(팔 탭 버튼 등)이 들어오거나, 차체를 몰면 '일시정지'.
14. **멈춰야 할 때는 중단.** 비상정지, 통신 끊김, 로봇 fault, 세션 없음, 팔 채널 재무장 필요면 '중단'. 해제한 뒤 처음(관측)부터 다시 한다.
15. **포커스·화면.** 순서는 화면 스레드에서 돌고, 조종 루프는 화면이 새 입력을 줄 때만 목표를 움직인다. 창이 포커스를 잃거나 집기 탭을 떠나거나 화면이 멈추면 자동 동작도 선다.
16. **책상 아래로 내려가지 않는다.** 하강 목표는 항상 `책상 높이 + 5 mm` 이상이다(물체 깊이 설정이나 미세 조정과 상관없이). 책상 높이를 보정하지 않았으면 집기를 시작하지 않는다.
17. **천천히 내려가고 올라온다.** 하강·들기는 손끝 0.06 m/s(평소의 40 %). 다른 이동은 평소 상한(0.15 m/s) 그대로.
18. **하강 전 확인(기본 켬).** 계획이 서면 영상에 집기 점을 보여 주고 멈춘다. A를 놓았다가 다시 눌러야 집게를 열고 내려간다. 이때 D-pad로 집기 점을 5 mm씩 옮길 수 있다(최대 ±3 cm).
19. **집게를 끝까지 닫지 않는다.** 물체별 닫힘 목표(블록 0.7, 공 0.6, 상한 0.9)까지만 닫는다(서보 과열 방지). 실제 값은 실기에서 정한다.
20. **모든 단계에 시간 제한.** 목표에 닿지 못하면(정지 0.5초) 하강·들기는 높이를 바꿔 한 번만 다시 하고, 그래도 안 되면 '실패'. 자동 재시도는 기본 0회(설정에서 1회).
21. **차체는 스스로 움직이지 않는다.** 자동 집기는 팔만 움직인다. 물체가 팔이 닿는 범위(영상의 초록 선) 밖이면 사람이 차체를 옮긴다.

## 실패 처리

| 상황 | 앱 동작 | 표시 |
|---|---|---|
| ACK 0.3초 없음, watchdog timeout | 의도를 유지하면 중립 → 확인 → 활성을 스스로 다시 밟음 | "통신 끊김" 알림, 진동 |
| 다른 조종기가 조종 중(not_owner), fault, 비상정지 | 강한 차단: 사용자가 손을 뗐다 다시 해야 재개 | 상단 칩 빨강 |
| 팔 목표 보정·거부 | 목표를 보정값 또는 마지막 수락값으로 | 노랑 알림, 약한 진동 |
| rosbridge 끊김 | 2초마다 다시 연결. UDP 조종은 계속 | "rosbridge 없음" |
| 카메라 끊김 | 2초마다 다시 연결 | "영상 없음" |
| 앱 종료 | 중립 2개 + disconnect, 진동 0, 잠자기 방지 해제, 설정 저장 | — |

## 실제 로봇 첫 시험 전에

- 바퀴를 띄운다(받침). 팔이 닿는 범위를 비운다. 전원 스위치를 손 가까이에 둔다.
- 속도 상한 10–30 %로 시작한다. 화면 비상정지는 소프트웨어 정지라 로봇 프로그램이 멈추면 듣지 않는다.
- 비상정지가 걸려도 팔은 토크를 유지한 채 선다(떨어지지 않게 하는 로봇 규칙).

### 자동 집기 첫 시험

1. 먼저 재 둔다: 집게 열림 폭, 3 cm 블록·4 cm 공을 손으로 집게 사이에 두고 닫았을 때 물체에 닿는 집게 값, 카메라가 팔에 붙었는지 차체에 붙었는지, 영상 해상도.
2. 바퀴를 띄우고 속도 상한 10 %, 책상 위에는 물체만 둔다. 사람 손은 작업 범위 밖에 둔다.
3. 집기 탭 → '보정 시작'으로 4단계를 마친다. 잔차가 8 mm보다 크면 점을 다시 찍는다. 빈 책상을 눌러 표시되는 좌표를 자로 잰 값과 비교한다.
4. 블록 하나를 초록 선 안 가운데에 두고, A를 누른 채 '하강 전 확인'까지만 간 뒤 **놓는다**. 영상의 집기 점과 실제 물체 위치 차이를 잰다(목표 15 mm 이내).
5. 하강 전 확인을 켠 채 전체 과정을 한다. 처음 세 번은 하강 중에 A를 놓아 **바로 서는지** 확인한다. 비상정지(B)도 하강 중에 한 번 확인한다.
6. 물체 종류·위치별로 성공·실패와 실패 이유(위치 오차, 깊이, 집게 폭, 영상 확인 오판)를 적는다.
