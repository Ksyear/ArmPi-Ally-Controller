# 조작표

Ally 내장 게임패드(XInput), 키보드, 터치 화면을 동시에 쓸 수 있다. 같은 축은 더한 뒤 −1..1로 자른다. 비상정지는 어느 입력이든 한 번에 걸린다.

## 게임패드

| 입력 | 평소(차체) | LB 누른 동안(팔) |
|---|---|---|
| 왼스틱 ↑↓ | 앞·뒤 | 손끝 x 앞·뒤 |
| 왼스틱 ←→ | 왼쪽·오른쪽 평행이동(메카넘) | 손끝 y 왼쪽·오른쪽 |
| 오른스틱 ←→ | 제자리 회전(왼쪽 = 좌회전) | 손목 pitch(왼쪽 = 올림) |
| 오른스틱 ↑↓ | — | 손끝 z 위·아래 |
| RT / LT | RT: 기울기 주행(설정에서 켰을 때만, 누른 동안) | 그리퍼 닫기 / 열기(누른 깊이만큼 빠르게) |
| **LB** | — | **팔 데드맨**: 누르는 동안만 팔이 움직인다. 놓으면 그 자리에 선다 |
| RB | 저속(× 0.5) | 저속 |
| D-pad ↑↓ | 속도 상한 ±10 % | z ±1 cm |
| D-pad ←→ | — | pitch ±5° |
| **B** | **비상정지** | **비상정지** |
| **View(⧉) 0.8초** | **비상정지 해제** | 같음 |
| X / Y | 영상 켜기·끄기 / 영상 크게 | 같음 |
| 왼스틱 누르기 | 팔 목표를 로봇 현재 자세로 맞춤 | 같음 |
| Menu(≡) | 설정 탭 열기·닫기(열려 있는 동안 조종 입력은 중립) | 같음 |

### 집기 탭에서 바뀌는 것

| 입력 | 집기 탭 |
|---|---|
| **A(누르고 있는 동안)** | **자동 집기 데드맨**: 누르고 있는 동안만 팔이 다음 단계로 움직인다. 놓으면 그 자리에 서고 '일시정지'. 다시 누르면 같은 단계부터 이어서 |
| A 다시 누르기(하강 전 확인) | 집기 점을 확인한 뒤 A를 놓았다가 다시 누르면 집게를 열고 내려간다 |
| D-pad ←→ | 인식된 물체를 왼쪽부터 차례로 고름 |
| D-pad ↑↓ / ←→(하강 전 확인 중) | 집기 점을 앞·뒤 / 왼·오른쪽으로 5 mm씩 옮김 |
| 스틱·LB·RT/LT | 평소처럼 조종된다. 자동 집기 중에 팔을 직접 움직이거나 차체를 몰면 자동 집기는 '일시정지' |
| B | 비상정지(자동 집기도 '중단') |

- 집기 탭에서는 D-pad가 속도 상한·z·pitch 대신 위 동작을 한다. 속도 상한은 안전 열 버튼이나 숫자 키로 바꾼다.

### 기울기 주행(설정 → 입력, 기본 꺼짐)

- **RT를 누른 동안만** 동작한다. RT를 누른 순간의 Ally 자세가 기준이다.
- 위쪽 가장자리를 앞으로(몸에서 멀리) 기울이면 전진, 뒤로 기울이면 후진. 오른쪽을 내리면 우회전, 왼쪽을 내리면 좌회전.
- 5° 안은 움직이지 않고, 설정한 각도(기본 25°)에서 스틱을 끝까지 민 것과 같다. 속도 상한·저속(RB)은 스틱과 똑같이 곱해진다.
- 스틱·터치 입력과 더해진다. LB(팔 데드맨)를 누르는 동안에는 쓰이지 않는다. 센서 값이 1초 넘게 갱신되지 않으면 0이 된다.
- `armpi-ally-cli tilt`로 로봇 없이 센서 값과 나가는 값을 볼 수 있다.

- 스틱 응답 곡선 `v' = sign(v)·|v|^1.6`(설정에서 1.0–2.5), 원형 데드존 0.15(설정).
- 스틱을 민 채 패드가 다시 연결되거나 창 포커스가 돌아오면, 스틱이 한 번 가운데로 돌아올 때까지 무시한다.

### Armoury Crate SE에 이 앱 등록하기(권장)

이 앱은 Armoury Crate SE가 내보내는 XInput 패드를 그대로 읽는다. 앱이 게임 라이브러리에 없으면 Ally의 **전체(글로벌) 버튼 설정**이 그대로 적용되므로, 평소에 버튼을 바꾸거나 자이로를 스틱에 연결해 두었다면 그 설정대로 로봇이 움직인다. 앱 전용 프로필을 만들어 기본 배치로 쓰는 것이 안전하다.

1. Ally 왼쪽의 Armoury Crate 버튼 → Armoury Crate SE → **게임 라이브러리**.
2. **추가** → 목록에 없으면 RB/LB로 파일 찾기 → `%USERPROFILE%\ArmPi_Ally_Controller\armpi-ally.exe` 선택.
3. 라이브러리에서 이 앱에 커서를 두고 **X** → 게임 프로필.
4. 프로필은 처음 만들 때 그때의 전체 설정을 물려받는다. 버튼 매핑을 **기본값**으로 되돌리고, 자이로→스틱 연결·버튼 맞바꿈·매크로·연사가 있으면 끈다. 제어 모드는 **게임패드**.
5. 앱을 실행하고 아래 패드 모니터(화면 오른쪽 아래)나 `armpi-ally-cli pads --seconds 10`으로, 손을 뗀 상태에서 두 스틱이 가운데(0.00)이고 A·B·LB·RB가 제 이름대로 눌리는지 확인한다.

- 나중에 전체 설정을 바꿔도 이미 만든 앱 프로필에는 반영되지 않는다(ASUS 안내 기준).
- 앱은 시작·포커스 복귀·패드 재연결 뒤 스틱이 한 번 가운데로 돌아오기 전까지 스틱 입력을 무시한다. 스틱이 계속 한쪽으로 치우쳐 있으면(예: 자이로가 스틱에 연결됨) 차체가 움직이지 않으니 프로필을 확인한다.

## 키보드

| 키 | 동작 |
|---|---|
| W/S, A/D, Q/E | 앞·뒤, 왼쪽·오른쪽 평행이동, 좌·우 회전 |
| Shift(누른 동안) | 팔 데드맨(LB와 같음) |
| I/K, J/L, U/O | 손끝 x, y, z |
| R/F | pitch 올림·내림 |
| G/H | 그리퍼 닫기·열기 |
| **Space** | **비상정지** |
| Ctrl+Space 0.8초 | 비상정지 해제 |
| 1–9, 0 | 속도 상한 10–90 %, 100 % |
| F1–F4 | 주행 / 팔 / 진단 / 설정 탭 |
| F5 | 집기 탭 |
| F11 | 전체 화면 ↔ 창 |

## 터치

| 화면 요소 | 동작 |
|---|---|
| 맨 위 오른쪽 끝 전원 아이콘 | 앱 끄기: 두 번 눌러야 꺼진다(3초 안). 끌 때 로봇은 중립, 연결 끊기, 설정 저장 |
| 오른쪽 위 빨간 **비상정지** | **닿는 순간** 비상정지(손을 뗄 때까지 기다리지 않음). 모든 화면에서 보임 |
| 길게 눌러 해제 | 0.8초 누르면 비상정지 해제 |
| 속도 30 / 60 / 100 %, 저속 | 속도 상한(오른쪽 안전 열) |
| 아래쪽 가상 스틱 | 앞·뒤·평행이동. 손을 떼면 중립 |
| 회전 슬라이더 | 제자리 회전 |
| 팔 조종 켜기 | 터치로 팔을 켜 둔다. 60초 동안 팔 입력이 없으면 저절로 꺼진다 |
| 팔 버튼 8개, 그리퍼 열기·닫기 | 누르는 동안 손끝 목표가 움직인다 |
| 팔 탭의 위·옆 그림 | 누르고 끌면 그 점이 목표가 된다. 목표는 속도 제한(0.15 m/s)으로 천천히 따라간다 |
| 팔 탭의 숫자 입력 | x·y·z(m), pitch(°)를 목표로. 역시 천천히 이동 |
| 연결 화면 숫자판 | 로봇 IP 입력(화면 키보드 대신) |
| 집기 탭: 영상 누르기 | 누른 곳에서 가장 가까운 인식 물체를 고른다. 물체가 없으면 그곳의 책상 좌표를 보여 준다(보정 확인용) |
| 집기 탭: 물체 목록 | 줄을 눌러 고른다. 색·이름·책상 좌표(cm)·팔이 닿는지 표시 |
| 집기 탭: 누르고 있는 동안 진행 | A와 같은 데드맨 버튼. 손을 떼면 선다 |
| 집기 탭: 앞·뒤·왼·오른·위·아래 | 하강 전 확인 중에 집기 점을 5 mm씩 옮김(최대 ±3 cm) |
| 집기 탭: 보정 시작 | 카메라 보정 5단계(관측 자세 → 책상 높이 → 대응점 4–6개 → 물체 높이 보정(선택) → 저장) |
| 집기 탭: 색 다시 찍기 | 영상에서 물체를 누르면 그 자리 색을 재고, 어느 색(빨간·파란·초록·노란)으로 쓸지 고른다. 블록과 공에 함께 적용되고 저장된다. '기본 색으로'로 되돌림 |
| 집기 탭: [시험] 차체로 다가가기 | 물체가 팔 범위 밖이면 차체가 물체 쪽으로 돌고 아주 천천히 다가간 뒤 다시 관측한다(속도 상한 30 % 이하에서만) |
| 집기 탭: [시험] 작업 영역 침입 감지 | 집는 동안 작업 영역에 큰 물체가 들어오면 일시정지(차체에 고정된 카메라용) |

**멀티터치**: 첫 손가락은 화면의 모든 요소를 누를 수 있고, 다른 손가락들은 가상 스틱·회전 슬라이더·누르고 있는 버튼(팔·그리퍼·집기 진행)·**비상정지**에 쓰인다. 예를 들어 왼손으로 가상 스틱을 잡은 채 오른손으로 팔 버튼이나 비상정지를 누를 수 있다(Windows 포인터 메시지).
