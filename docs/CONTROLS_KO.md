# 조작 안내

현재 버전 0.4.1. Ally 내장 게임패드(XInput), 키보드, 터치 화면을 동시에 쓸 수 있다. 같은 축은 더한 뒤 −1..1로 자른다. 비상정지는 어느 입력으로든 한 번에 걸린다. 안전 규칙은 [`SAFETY_KO.md`](SAFETY_KO.md).

## 준비

### Armoury Crate SE에 이 앱 등록하기(권장)

이 앱은 Armoury Crate SE가 내보내는 XInput 패드를 그대로 읽는다. 앱이 게임 라이브러리에 없으면 Ally의 **전체(글로벌) 버튼 설정**이 그대로 적용되므로, 평소에 버튼을 바꾸거나 자이로를 스틱에 연결해 두었다면 그 설정대로 로봇이 움직인다. 앱 전용 프로필을 만들어 기본 배치로 쓰는 것이 안전하다.

1. Ally 왼쪽의 Armoury Crate 버튼 → Armoury Crate SE → **게임 라이브러리**.
2. **추가** → 목록에 없으면 RB/LB로 파일 찾기 → `%USERPROFILE%\ArmPi_Ally_Controller\armpi-ally.exe`(앱을 둔 곳) 선택.
3. 라이브러리에서 이 앱에 커서를 두고 **X** → 게임 프로필.
4. 프로필은 처음 만들 때 그때의 전체 설정을 물려받는다. 버튼 매핑을 **기본값**으로 되돌리고, 자이로→스틱 연결·버튼 맞바꿈·매크로·연사가 있으면 끈다. 제어 모드는 **게임패드**.
5. 앱 화면 오른쪽 아래 패드 표시나 `armpi-ally-cli pads --seconds 10`으로, 손을 뗀 상태에서 두 스틱이 가운데(0.00)이고 A·B·LB·RB가 제 이름대로 눌리는지 확인한다.

- 나중에 전체 설정을 바꿔도 이미 만든 앱 프로필에는 반영되지 않는다(ASUS 안내 기준). 화면 문구는 Armoury Crate SE 판에 따라 조금 다를 수 있다.
- 앱은 시작·포커스 복귀·패드 재연결 뒤 스틱이 한 번 가운데로 돌아오기 전까지 스틱 입력을 무시한다. 스틱이 계속 한쪽으로 치우쳐 있으면(예: 자이로가 스틱에 연결됨) 차체가 움직이지 않으니 프로필을 확인한다.

### 시작과 끄기

- 바탕화면 바로가기나 `armpi-ally.exe`로 시작한다. 같은 Ally에서 두 번 실행하면 두 번째는 뜨지 않는다.
- **끄기**: 맨 위 오른쪽 끝 전원 아이콘을 **두 번**(3초 안) 누른다. 한 번 누르면 "한 번 더 누르면 앱을 끕니다"가 뜬다. 끌 때 로봇은 중립, 연결 끊기, 설정 저장. 설정 탭의 '앱 종료'도 같다.

## 화면 구성

```
┌ 상태 줄: 연결·채널·조종권 | 배터리·ACK·영상·ROS·패드 | 주행 팔 집기 진단 설정 | 전원 ┐
│ 카메라 영상 + 표시                    │ 탭 내용               │ 안전 열       │
│ (상태 단어, 팔 목표, 주행 벡터, 알림)    │                       │ 비상정지·해제  │
│                                       │                       │ 속도 상한·저속 │
├ 아래 줄: 가상 스틱 · 회전 슬라이더 · 팔 켜기 · 팔 버튼 · 그리퍼 · 패드 표시 ┤
```

- **상태 줄**: 왼쪽은 연결·차체/팔 채널 상태·조종권, 오른쪽은 로봇 배터리, Ally 배터리, ACK 지연, 영상 fps, rosbridge, 패드. 상태는 색·모양·글자로 함께 보인다(● 정상, ○ 대기, ▲ 주의, ■ 위험).
- **안전 열**(오른쪽, 늘 보임): 비상정지, 길게 눌러 해제, 속도 상한 30/60/100 %, 저속.
- **연결 화면**: 로봇이 연결되지 않으면 영상 대신 IP 숫자판, '로봇 찾기', 패드 안내가 나온다. 이때도 **설정 탭은 열린다**. 다른 탭을 누르면 "로봇에 연결하면 쓸 수 있습니다" 알림이 뜬다.

## 게임패드

| 입력 | 평소(차체) | LB 누른 동안(팔) |
|---|---|---|
| 왼스틱 ↑↓ | 앞·뒤 | 손끝 x 앞·뒤 |
| 왼스틱 ←→ | 왼쪽·오른쪽 평행이동(메카넘) | 손끝 y 왼쪽·오른쪽 |
| 오른스틱 ←→ | 제자리 회전(왼쪽 = 좌회전) | 손목 pitch(왼쪽 = 올림) |
| 오른스틱 ↑↓ | — | 손끝 z 위·아래 |
| RT / LT | RT: 기울기 주행(설정에서 켰을 때, 누른 동안) | 그리퍼 닫기 / 열기(누른 깊이만큼 빠르게) |
| **LB** | — | **팔 데드맨**: 누르는 동안만 팔이 움직인다. 놓으면 그 자리에 선다 |
| RB | 저속(× 0.5) | 저속 |
| D-pad ↑↓ | 속도 상한 ±10 % | z ±1 cm |
| D-pad ←→ | — | pitch ±5° |
| **A** | 집기 탭: 자동 집기 데드맨(아래) | 같음 |
| **B** | **비상정지** | **비상정지** |
| **View(⧉) 0.8초** | **비상정지 해제** | 같음 |
| X / Y | 영상 켜기·끄기 / 영상 크게 | 같음 |
| 왼스틱 누르기 | 팔 목표를 로봇 현재 자세로 맞춤 | 같음 |
| Menu(≡) | 설정 탭 열기·닫기 | 같음 |

- 스틱 응답 곡선 `v' = sign(v)·|v|^1.6`(설정 1.0–2.5), 원형 데드존 0.15(설정).
- 스틱을 민 채 패드가 다시 연결되거나 창 포커스가 돌아오면, 스틱이 한 번 가운데로 돌아올 때까지 무시한다.

### 집기 탭에서 바뀌는 것

| 입력 | 집기 탭 |
|---|---|
| **A(누르고 있는 동안)** | **자동 집기 데드맨**: 누르고 있는 동안만 다음 단계로 진행한다. 놓으면 그 자리에 서고 '일시정지'. 다시 누르면 같은 단계부터 |
| A 다시 누르기(하강 전 확인) | 집기 점을 확인한 뒤 A를 놓았다가 다시 누르면 집게를 열고 내려간다 |
| D-pad ←→ | 인식된 물체를 왼쪽부터 차례로 고름 |
| D-pad ↑↓ / ←→(하강 전 확인 중) | 집기 점을 앞·뒤 / 왼·오른쪽으로 5 mm씩(최대 ±3 cm) |
| 스틱·LB·RT/LT·화면 버튼 | 평소처럼 조종된다. 자동 집기 중에 직접 조종하면 자동 집기는 '일시정지' |
| B | 비상정지(자동 집기도 '중단') |

- 집기 탭에서는 D-pad가 속도 상한·z·pitch 대신 위 동작을 한다. 속도 상한은 안전 열이나 숫자 키로 바꾼다.
- 포커스 복귀·탭 전환·보정·직접 조종 뒤에는 A를 한 번 놓았다가 다시 눌러야 이어진다.

### 기울기 주행(설정 → 입력, 기본 꺼짐)

- **RT를 누른 동안만** 동작한다. RT를 누른 뒤 들어온 첫 센서 값의 자세가 기준이다(누르자마자 튀지 않는다).
- 위쪽 가장자리를 앞으로(몸에서 멀리) 기울이면 전진, 뒤로 기울이면 후진. 핸들처럼 돌려 오른쪽을 내리면 우회전, 왼쪽을 내리면 좌회전.
- 5° 안은 움직이지 않고, 설정한 각도(기본 25°, 12–45°)에서 스틱을 끝까지 민 것과 같다. 속도 상한·저속은 스틱과 똑같이 곱해진다.
- 스틱·터치 입력과 더해진다. LB를 누르는 동안에는 쓰이지 않는다. 센서 값이 1초 넘게 갱신되지 않으면 0. 포커스 복귀·패드 재연결 뒤에는 RT를 한 번 놓았다가 눌러야 한다.
- `armpi-ally-cli tilt --seconds 20`으로 로봇 없이 센서 값과 나가는 값을 볼 수 있다.

| 길게 눌러 해제 | 0.8초 누르면 비상정지 해제 |

**멀티터치**: 첫 손가락은 화면의 모든 요소를 누를 수 있고, 다른 손가락은 가상 스틱·회전 슬라이더·누르고 있는 버튼(팔·그리퍼·집기 진행)·비상정지에 쓰인다. 버튼은 손가락이 **닿는 순간**에만 그 손가락을 잡으므로, 대고 있던 손가락 아래로 버튼이 나타나도 눌린 것이 되지 않는다.

## 카메라 보정(집기 탭 → 보정 시작)

| 단계 | 하는 일 |
|---|---|
| 1 관측 자세 | 물체를 보는 자세를 정한다('기본 자세로 정하기' 권장). 팔은 움직이지 않는다 |
| 2 책상 높이 | 팔 끝을 책상 면에 닿을 듯 말 듯 내리고 '여기가 책상' |
| 3 대응점 | '관측 자세로 이동' → 영상에서 책상 위 표시를 누름 → 팔 끝을 그 표시 위에 맞추고 '이 점 저장'. 4–6개를 넓게 |
| 4 물체 높이(선택) | 책상 표시를 누르고, 그 위에 블록을 올려 윗면 가운데를 누른다. 비스듬한 카메라 때문에 밀리는 양을 잰다 |
| 5 저장 | 잔차(책상 mm, 영상 px) 확인 후 저장. 8 mm보다 크면 점을 다시 찍는다 |

카메라가 팔에 달렸든 차체에 달렸든 같은 절차다. 보정은 `%LOCALAPPDATA%\ArmPi_Ally_Controller\vision_calib.json`에 저장되고, 영상 해상도가 바뀌면 다시 해야 한다.
